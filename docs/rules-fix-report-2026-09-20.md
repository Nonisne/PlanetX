终局实现完整的「首次发现 → 冻结 → 最后机会 → 房主揭示 → 最终积分」流程；最后机会不移动棋子，最终理论整批原子提交，终局核对尚未评审论文时不再罚时。单机保存待处理／已完成阶段、冻结天窗、撤销边界及揭示结果。

独立代码复核另外发现并修复：

1. 处罚触发的新论文阶段不能插到已有阶段队列前；使用绝对事件 ID 与 FIFO 队列。
2. 到期论文按扇区升序评审，仅当前扇区公开；错误的相同到期主张合批，按玩家顺序落罚，更外圈论文保持保密。
3. 零提交阶段也有唯一 ID；联机声明和提交必须携带匹配的 `phaseId`，缺失或陈旧请求被拒绝。
4. 完整揭示不能推翻已有评审，也不能让已经判错的论文重新得分；历史罚时保留。
5. 稀疏数组不能绕过完整答案校验。

## 使用与边界

- 正式使用前重启现有服务并刷新页面；重启会清空内存房间，请在当前对局结束后操作。
- 旧存档的既有耗时不会自动换算；要从头采用全部修订规则，请新开一局。
- 单机仍是个人记录台，不含官方 Bot；不生成或求解谜题，定位判定和完整答案均需从官方 app 录入。
- 未实现实体论文标记库存、房间持久化、严格预选论文内容和延迟公开会议线索；这些仍属于原审计中注明的产品边界，不应宣称为完整官方复刻。
- 揭示校验完整性、天体类型、一个 X行星及已有评审一致性，不验证整盘所有天体数量与邻接规律。
