# 星图工作台与行动历史表验收

日期：2026-09-20。

## 交付范围

- 桌面为参考资料、星图、当前行动三栏；历史与积分移至底部通栏。
- 星图不再被内部固定侧栏挤压；标注、图例和时间轨说明放在图下。
- 顶部只保留关键状态，详细说明和次要面板按需展开。
- 历史按真实日志顺序，一列一名玩家、一行一条记录；不按玩家个人时间排序或凑回合。
- 会议和评审罚时跨列显示；保留原始耗时；他人的私有结果不进入文本或 DOM 属性。
- 已公开的论文和终局定位结果正常显示；切换对局及进退房间清除旧记录的展开键，普通面板偏好保留。

没有修改规则引擎、服务器、联机协议、计分和历史数据格式，没有新增依赖。旧 `actionRounds` 接口保留兼容，仅新 UI 不再使用。

## 浏览器验收

使用独立临时服务 5191 端口，不重启用户已有服务或对局。测试数据为人工验收示例，不代表真实谜题答案。

- 三人房间 ETVAEA：研究、扫描、公共会议、勘测依次产生四条记录，位于正确玩家列；会议为三列跨度的公共事件行。
- 月光页面不包含星河的私有研究文本；星河页面展示自己的研究结果，不展示月光的扫描天体或远航的勘测数量。
- 另一玩家操作带来的 SSE 重绘后，已打开的历史和结果明细保持展开。
- 390px 页面表格独立横向滚动；标注重绘前后 `scrollLeft=120`、`scrollTop=99.5` 保持一致；「查看最新」可定位最后一行。
- 1280×720 为三栏，1024×768 为星图与行动双栏，390px 和 320px 为星图优先单列；这些宽度下页面未横向溢出。
- 320px 专家盘显示完整 18 扇区，窄屏初次加载默认折叠参考线索；实际完成研究后再扫描，两条记录分别占行，单机为两列。
- 320px 扫描选择和确认按钮均在页面边界内；390px 边缘扇区的标注弹层横向范围为 55–335px，没有越界。
- 四个验收页面未捕获浏览器控制台错误。一次非法彗星勘测被既有规则拒绝，改为合法的小行星勘测后正常记录，没有为通过验收改动规则。
