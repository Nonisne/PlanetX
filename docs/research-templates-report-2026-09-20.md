# 研究模板修正与验收（2026-09-20）

## 本次范围

- 参考官方网页版 `https://web.planetxapp.com/` 的研究界面与发行方规则书 `https://static.foxtrotgames.com/content/FG_PX_Rulebook_P1B_web.pdf` 第 10、18 页；只对齐命题结构、空间关系与量词，不复制官方谜题库。
- A–F 恰好六个不同命题，名称只含一种或两种普通天体；每题恰好一条事实。
- 单天体题为「所有该类天体位于一段不超过 N 个连续扇区内」，起点未知，允许跨越首尾边界。
- 双天体题为相邻、正对或最短环形距离 N 格以内，分别支持「没有任何」「至少有一个」「每个都对应至少一个」；至少一个包含全部，距离上限包含边界。
- 删除指定扇区计数、精确邻接数量、精确同类间距和追加多句的联合研究。标题不提前公开关系、量词或距离。
- 增加默认折叠的研究说明，并修复长双天体名称在按钮内被截断的问题。

初始线索仍为四条普通天体排除，不提供空域或 X 排除；观测空域、会议时机、私有查询、耗时和记录模式流程不变。

## 可解性

相对空间关系不能区分某些镜像布局，因此不再承诺「基础规律＋六道研究＋会议」无需观测就能唯一还原整盘，也不靠追加句子或丢弃合法棋盘制造这一保证。

全部 4,446 张合法标准盘继续均匀抽取。所有研究线索真实且对基础候选集有信息量，会议选择会消除相同完整表观观测下的 X／真正空域歧义。充分的勘测／扫描观测与线索合用可唯一还原完整棋盘；正常游玩仍需要观测和推理，不提供自动解题，也不宣称难度等同官方题库。

## 自动化验证

最终命令：`PUZZLE_EXHAUSTIVE=1 node tests/all.test.js`。

- **14 个文件、318 项：316 通过、2 失败、0 跳过；退出码 1，不能记为全套通过。**
- 谓词纯模块 37 项、谜题 22 项、界面 52 项全部通过；其余 HTTP／SSE、隐私、历史与终局等文件均通过。
- 独立解释器覆盖 729 个小棋盘排列，验证量词、连续范围与最短距离；覆盖 12／18 格转动、镜像和环形边界。
- 独立枚举并认证全部 4,446 张合法标准盘、26,676 组私有初始线索；每盘六道研究各一句，加会议最多七条陈述。
- 新标题／单句要求、中文谓词预言机、折叠说明与标题换行均先观察对应失败，再实现修复。
- 修复代码审查发现的冷启动计时盲点：通过独立模块实例测量首次枚举、特征缓存与生成，避免先前用例预热缓存；最终全量日志测得 91ms，低于原有 2 秒预算。
- 两项失败来自已有启停脚本名称与 `tests/launcher.test.js` 旧名称不一致：缺少旧名 `一键启动.command`，以及隔离测试无法以该旧名启动。未修改启动器、脚本命名或这些测试。

完整日志：`audit/evidence/research-templates-tests-2026-09-20.txt`。

独立规格审查与代码质量审查均已完成。冷启动覆盖问题另作反例复核：只在内存里将首次引擎初始化延迟 2100ms，修正后的测试在 2215ms 正确触发预算断言；无注入对照为 94ms、21 通过／1 穷举跳过。预期失败仅来自故意注入的延迟，不是当前实现的性能故障；原始项目文件未被注入修改。复核证据：`audit/evidence/research-cold-budget-review-2026-09-20.txt`。

## 浏览器验收

在临时项目副本与独立的 `127.0.0.1:53905` 服务上创建双玩家验收房间 EYKE8J，不连接现有用户房间，不调用真实项目的启停脚本。

| 检查 | 实测结果 |
| --- | --- |
| 单天体研究 | 研究甲选择 D「小行星」，得到一条「所有小行星都位于一段不超过 4 个连续扇区内。」 |
| 双天体研究 | 研究乙选择 E「气体云和矮行星」，得到一条「每个气体云都位于至少一个矮行星的 2 个扇区以内。」 |
| 时间与进度 | 两次研究各耗时 1；各自显示 1/6，不把另一人的研究算作自己已获得 |
| 未研究内容 | 行动前只显示天体命题名称；研究乙看不到研究甲的单体正文，会议到点前没有正文 |
| 行动历史 | 一列一人、一行一行动；本人可展开具体线索，他人对应格只显示「结果未公开」 |
| 刷新恢复 | 两人刷新后仍各自仅有本人正文；整个页面 DOM 均不含另一人的结果文字 |
| 默认说明 | 研究说明初始收起，展开后选择课题触发重绘仍保持展开 |
| 桌面与窄屏 | 1280、390、320 像素下检查截图与 DOM 几何；所有课题名完整，320／390 页面宽度等于视口宽度 |
| 控制台 | 两个验收标签的 warning／error 日志均为空 |

原样式的 `white-space: nowrap` 在约 81 像素宽的课题按钮里裁掉长名称。修复后标题限制在按钮内容宽度内自动换行；实际测量标题的内容宽度未超过元素宽度，边界均位于按钮内。

## 生效方式与边界

- 服务端研究生成规则已变更，需要先结束现有对局，再重启服务并新建内置对局。已有房间不迁移；直接重启会丢失内存房间。
- 浏览器样式和说明刷新即可加载，但只刷新页面不会替换现有房间的研究线索。
- 本次未重启用户现有服务；内置专家盘、Bot、难度均衡及持久化仍不在本次范围。
- 验收结束后已恢复默认浏览器视口、关闭本次两个验收标签，并只停止本次创建的临时服务（退出码 0）。
