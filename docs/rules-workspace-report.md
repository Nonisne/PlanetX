# 本轮规则与星图工作区改进

## 实现范围

| 项目 | 当前实现 |
| --- | --- |
| 初始线索 | 每位玩家独立选择 0、4、8、12 条，默认选择 4；领取后锁定，确认准备前必须领取，0 条也需要确认领取。 |
| 私有标注 | 领取成功后的本人权威视图立即同步星图排除标记；刷新可恢复，不覆盖无关手写标记，不接收其他玩家的线索。 |
| 无意义排除 | 初始线索仅涉及四类普通天体；排除基础规则已经确定的“非质数扇区没有彗星”。不提供空域线索。 |
| 彗星约束 | 非法扇区不显示彗星图标，不允许提交彗星论文；彗星勘测起终点只提供可见的质数编号扇区。终局论文使用相同约束。 |
| 触发时机 | 天窗起点离开事件标记时触发，而不是进入时；支持跨圈、多事件跨越与评审罚时。 |
| 图标间距 | 增大扇区内天体图标间距；非法彗星位置留空，其他图标不跳位。 |
| 论文进度 | 放在星图左侧，以“扇区／玩家图标与轨道”两列表格展示；他人未公开的天体仍保密。 |
| 会议线索 | 采用 X 与一种普通天体的单个相对关系：相邻、相对或 N 格内，结合无、至少一个或全部等量词。 |
| 再次提交 | 后续阶段可以对同一未公开扇区提出不同天体假说；禁止重复提交相同结果，也不能在同阶段对同扇区提交两种天体。 |
| 基础规律 | 明确标准盘 1 颗、专家盘 4 颗矮行星。内置仍仅支持标准盘，专家盘可用记录模式。 |
| 合法选项 | 已公开正确的扇区不再进入论文选项；普通阶段、声明容量与终局共同读取合法选项，表单增加内边距。 |
| 行动与积分 | 普通行动不展示等待和论文提交；事件阶段保留专用提交表单。每位玩家积分以两行表格展示天体单位分值、首对奖励、定位 X 与合计，第二行是实际得分。 |

## 歧义盘面过滤

- 基础规则允许的 4,446 个盘面仍全部保留用于验证及观测等价比较。
- 从中排除 18 个不能被允许的单条相对关系会议区分的盘面，只在剩余 4,428 个中均匀抽题；不是硬编码排除先前举例的盘面。
- 不把“被过滤盘面不会抽到”当成玩家推理前提。判定会议能否区分答案时，仍与原始 4,446 个盘面比较。
- 穷举检查覆盖 4,428 个可出题盘面和 17,712 组私有线索；每个基础合法盘面均有 32 个真实、非平凡的初始排除项，足够领取 12 条。

## 同格前后与执行顺序

- 先比较累计耗时：落后的玩家先行动。
- 累计耗时相同时，先到者在后，后到者按顺时针放在所有已到达玩家的前方。
- 行动和论文提交均由先到者优先，不受房主身份、加入顺序或屏幕左右方向影响。初始位置没有到达记录时仍按加入顺序打破平局。
- 例如乙先到 5 号、甲后到 5 号：甲的棋子领先乙，但乙先行动、先提交论文，即使甲是先加入的房主。

## 事件与评审边界

- 内置模式一次行动跨越阶段 9、会议 10、阶段 12 时，先完成阶段 9 的提交与到期评审，再公布会议 10，最后进入阶段 12。
- HTTP 返回和 SSE 推送在前序阶段完成之前均不包含待公布会议线索。
- 星图高亮与顶部状态读取实际待处理阶段，不再把“当前站在事件格”误当作“刚离开事件格”。
- 离线记录等待同行评审时，后续会议提示与排队阶段高亮暂停，顶部显示同行评审；评审后恢复。`eventsAt` 仍只表示当前标记位置。

## 浏览器验收

使用独立随机端口服务与临时标签页，没有操作现有对局：

- 实走单人领取 12 条、立即标图、数量锁定与刷新恢复，以及 0 条领取。
- 双玩家分别领取 0、8 条，核对线索私有；实走后加入者先到同格，验证后到者领先、先到者优先提交和行动。
- 检查桌面布局、390／320 像素窄屏；页面没有整体横向溢出，积分表在自身区域横向滚动。
- 检查 18 扇区记录盘、质数彗星端点、论文表单、两列表格、两行积分表。
- 实走累计耗时 8→12 的混合事件：阶段 9 时会议保密，完成后会议公开并进入阶段 12；刷新后高亮仍指向阶段 12。
- 临时服务与标签页已关闭，视口覆盖已恢复；最后一次验收页面未报告 JavaScript 错误或警告。

## 升级注意

这是前后端一起更新，不能只刷新浏览器。**先结束所有现有对局，再一键关闭、一键启动，并让所有玩家刷新后开新局。**

房间仍保存在服务器内存中，重启会清空房间；代码备份不能恢复进行中的对局。本轮没有重启用户现有服务、修改其 `.planetx` 控制信息、提交 Git 或创建新分支；未改动启停脚本。
